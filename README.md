# CHAOS CLUB

Party-game website for 4–6 friends, in English and German. The public site uses the frozen CHAOS CLUB 4.0.1 standalone offline build. Seven flagship games and the original classic modes remain in the downloadable source.

## Play

Open the website and choose a game. The standard experience works on one shared device without an account. Drinking is optional.

## Multiplayer

Local Wi-Fi rooms for Social Radar, Comedy Battle, and Bluff Club require a separate Python room server and are **not publicly deployed** at this domain. The original room service uses unencrypted HTTP/WebSockets, so it must only run on a trusted LAN. Consult the LAN package for instructions.

## Release limitations

Native physical-device and human group playtests remain outstanding. This is a public distribution of a previously frozen internal build, not a claim of independently validated gameplay quality.
